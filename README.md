# TreinoDePython


Exercícios realizados para estudo de introdução a Python.

Este repositório tem o intuito de documentar meus estudos de introdução a Python.



## Blocos


| Bloco | Pasta | Conteudo |
|:---:|:---:|:---:|
| Bloco 1 | Manipulação de dados | Tipos de variáveis, entrada e saida (ex: int; float; string; input; print; format) |
| Bloco 2 | Manipulação de dados | Manipulação de operações aritméticas (ex: operadores aritméticos; manipulação de contas; formatação) |
| Bloco 3 | Manipulação de dados | Manipulação de Strings (ex: metodos diversos para Strings)|
| Bloco 4 | Estruturas condicionais | Exercícios para pratica com condicionais (ex: if/elif/else; match/case)|
| Bloco 5 | Estruturas de repetição | Exercicios para pratica com repetição (ex: for; while)|
| Bloco 6 | Estrutura de dados | Exercicios para pratica com estrutura de dados (ex: listas; dicionarios)|
